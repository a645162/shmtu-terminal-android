## 这软件能干什么

海大终端 Android 版帮你把校园一卡通的消费记录同步到手机上，同时支持账单统计分析、热水信息查询，方便日常校园生活。

核心流程很简单：**登录 → 同步 → 看账单**。

同步完成后，你不仅能查看每笔消费明细，还能通过账单统计功能按时间、分类、商户等维度分析消费趋势。

## 第一次用？

1. 打开应用，进入账号设置
2. 添加你的学号和密码
3. 验证码模式先选手动输入
4. 点击同步账单
5. 查看首页消费概览和账单明细
