# 常见问题

## 安装与启动

### APK 安装失败

- 确认手机系统为 Android 8.0 及以上
- 在系统设置中允许"未知来源"应用安装
- 如果覆盖安装失败，先卸载旧版本再安装

### 应用闪退

- 尝试清除应用数据（设置 → 应用 → 海大终端 → 清除数据）
- 确认 APK 版本与手机架构匹配（arm64-v8a 为主）
- 如果问题持续，请提交 Issue 并附上系统版本和手机型号

## 账号与登录

### 忘记密码怎么办

应用使用校园 CAS 统一认证的密码，如果忘记请通过学校渠道重置，应用本身无法重置密码。

### 登录一直失败

常见原因及解决方法：

1. **密码错误**：重新输入密码，注意大小写和特殊字符
2. **验证码错误**：切换到手动输入模式，确保验证码输入正确
3. **CAS 系统维护**：尝试在浏览器中登录 CAS，如果浏览器也无法登录则说明系统在维护
4. **网络问题**：确认能正常访问校园网

### 多个账号怎么管理

应用支持"身份 → 账号"两级结构。一个身份下可以添加多个账号，每个账号独立管理。例如：

- 身份"我自己"下添加本科号和研究生号
- 身份"家长"下添加家长关注的账号

## 账单同步

### 同步后没有数据

- 确认账号有消费记录（新卡可能没有历史消费）
- 尝试使用全量同步而非增量同步
- 检查同步过程中是否有错误提示

### 数据重复

不会出现数据重复。应用使用 `OnConflictStrategy.IGNORE` 策略，按交易号去重，重复同步会自动跳过已有记录。

### 同步速度慢

- 首次全量同步需要拉取所有历史数据，速度较慢是正常的
- 日常使用增量同步，只拉取新增数据，速度很快
- 网络状况差时同步会变慢

### 一个身份下有多个账号怎么同步

应用支持三种同步粒度：单账号同步、身份同步（同步该身份下所有账号）、全部同步。在首页或账单页的同步按钮可以选择同步范围。

## 账单统计与分类

### 账单分类不准确

账单分类基于内置规则文件（`type.json`、`position.json`、`schedule.json`），如果商户名称发生变化可能导致分类偏差。这类问题需要更新规则文件才能修复。

### 统计数据与账单明细不一致

- 确认统计的时间范围与筛选条件是否正确
- 统计数据来源于本地数据库，确保已成功同步账单
- 如果刚完成同步，返回统计页面刷新即可

## 验证码

### 验证码一直识别错误

1. 切换到手动输入模式确认验证码内容
2. 如果是远程 OCR，检查服务器是否正常运行
3. 如果是本地 OCR，确认模型文件完整
4. 临时使用手动模式，避免被识别错误阻塞

### 远程 OCR 连接失败

- 确认 OCR 服务器地址和端口配置正确
- 确认服务器正在运行
- 确认手机能访问服务器所在网络
- 尝试 ping 服务器地址排查网络连通性

### 本地 OCR 不可用

- 确认 NCNN 和 OpenCV 库已正确打包进 APK
- 检查是否使用了正确的 APK 架构版本
- 查看应用日志获取详细错误信息

## 热水查询

### 查询不到热水信息

- 确认在校园网内网环境（连接校园 WiFi）
- 确认楼栋编号正确
- 热水系统可能暂时维护中

### 热水数据不更新

热水数据是实时查询的，不会缓存。每次查询都从服务器获取最新数据。如果数据看起来不变，可能是热水系统本身数据未更新。

## 数据安全

### 密码存储安全吗

密码使用 Android `EncryptedSharedPreferences`（AES256_GCM 加密）存储，这是 Android 官方推荐的安全存储方案。在非 root 设备上，即使应用数据被提取也无法直接读取密码。

### 账单数据存储在哪里

每个账号的账单数据存储在独立的 Room 数据库文件中，位于应用内部存储目录。其他应用无法访问。

### 删除账号会清除数据吗

是的，删除账号会同时删除该账号对应的数据库文件，数据不可恢复。操作前请确认不再需要该数据。

## 其他

### 如何构建 APK

```bash
# Debug 版本
./gradlew assembleDebug

# Release 版本
./gradlew assembleRelease
```

生成的 APK 在 `app/build/outputs/apk/` 目录下。
