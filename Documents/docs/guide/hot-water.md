# 热水查询

热水查询功能可以实时查看宿舍楼栋的热水供应情况，包括温度、水位等信息。

## 功能入口

1. 打开应用，点击底部导航栏的 **功能大全** 页面
2. 进入热水查询模块

## 查询信息

每次查询返回以下信息：

| 字段 | 说明 |
|------|------|
| 温度 | 当前热水温度（摄氏度） |
| 水位 | 热水储水量百分比 |
| 楼栋号 | 查询的楼栋编号 |

## 关注楼栋

你可以将常用的楼栋添加到"关注列表"，方便快速查询：

1. 在热水查询页面点击 **添加楼栋**
2. 输入或选择楼栋编号
3. 确认添加

关注列表会持久化存储到本地 Room 数据库，应用重启后依然保留。

::: tip
热水数据本身是实时查询的，不会保存历史记录。每次查询都从服务器获取最新数据。
:::

## 认证方式

热水系统的认证流程与 E-pay 账单系统不同：

- **E-pay**：使用标准 CAS 认证
- **热水系统**：使用微信认证（WeChat Auth）流程

热水查询的认证步骤：

1. 访问热水系统 URL → 返回 302 重定向
2. 获取 `wengine_new_ticket`（微信票证）
3. 获取 CAS `execution` 令牌
4. 提交 CAS 登录
5. 跟随重定向获取业务系统会话
6. 用会话查询热水数据

::: warning
热水系统地址为 `http://hqzx.shmtu.edu.cn/cellphone/getHotWater`，需要校园网内网访问。如果不在校园网内，需要先连接校园 WiFi 或 VPN。
:::

## 数据解析

热水数据以 HTML 格式返回，应用通过 `HotWaterParser` 解析提取：

- 温度数值
- 水位百分比
- 楼栋编号

解析结果直接展示在界面上，不做持久化存储。

## 常见问题

### 查询失败

- 确认是否在校园网内网环境
- 检查账号密码是否正确
- 热水系统可能暂时不可用，稍后重试

### 楼栋编号不知道

- 咨询宿管或同学获取
- 常见楼栋编号一般为数字编码

### 数据异常

- 热水系统维护期间可能返回异常数据
- 确认不是网络问题后，等待系统恢复
