# 快速开始

本文帮你从零开始配置并使用海大终端 Android 版。

## 安装应用

1. 从项目 Release 页面下载最新 APK 文件
2. 在手机上安装（可能需要允许"未知来源"安装）
3. 打开应用，进入主界面

> 如果你是开发者，可以自行构建：
>
> ```bash
> ./gradlew assembleDebug
> ```
>
> 生成的 APK 在 `app/build/outputs/apk/debug/` 目录下。

## 添加账号

首次使用时应用没有任何账号数据，需要手动添加：

1. 点击底部导航栏的 **账号** 页面
2. 点击 **添加身份**，输入一个名称（如"我自己"）
3. 在身份下点击 **添加账号**
4. 填写 **学号** 和 **密码**（校园 CAS 统一认证的账号密码）
5. 保存

一个身份下可以添加多个账号（如本科生号和研究生号），每个账号独立管理账单数据。

## 首次同步

1. 进入 **首页** 或 **账单** 页面
2. 点击同步按钮（通常在右上角）
3. 首次同步时会弹出验证码输入框
4. 输入验证码后，应用开始拉取消费记录
5. 同步完成后，首页会显示今日和本月消费概览

::: tip 首次同步推荐使用全量同步
首次使用建议做一次全量同步，将所有历史消费记录拉取到本地。之后日常使用增量同步即可，速度更快。
:::

> 验证码默认为手动输入模式。如果你希望自动识别，请参考 [OCR验证码](/guide/ocr-captcha) 配置。

## 验证码模式

应用支持三种验证码处理方式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 手动输入 | 每次弹出验证码让你手动输入 | 首次使用、偶尔同步 |
| 远程 OCR | 连接 OCR 服务器自动识别 | 有 OCR 服务器部署 |
| 本地 OCR | 使用设备端 NCNN 模型推理 | 日常使用，无需服务器 |

推荐新手先使用 **手动输入** 模式，熟悉后再切换到 OCR 模式。

## 查看账单

同步完成后：

- **首页**：显示今日消费、本月消费等概览信息
- **账单页**：按时间线展示每笔消费的详细记录，包括金额、商户、时间等

## 查询热水信息

1. 进入 **功能大全** 页面
2. 选择或添加关注的楼栋
3. 点击查询，查看当前热水的温度、水位信息

热水数据为实时查询，不缓存历史记录。详细说明见 [热水查询](/guide/hot-water)。

## 查看账单统计

同步完账单数据后，你可以查看消费统计：

1. 进入 **功能大全** 页面
2. 点击账单统计
3. 按时间、分类、商户等维度查看消费分析

统计数据来自本地数据库，无需网络即可查看。

## 配置 OCR 自动识别

如果不想每次同步都手动输入验证码，可以在设置中配置 OCR：

1. 进入 **设置** 页面
2. 选择 OCR 模式（远程 OCR 或本地 OCR）
3. 远程 OCR 需要填写服务器地址和端口
4. 本地 OCR 无需额外配置，开箱即用

详细配置说明见 [OCR验证码](/guide/ocr-captcha)。
