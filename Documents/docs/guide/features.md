# 功能介绍

海大终端 Android 版基于 Jetpack Compose 构建，采用 MVVM + Clean Architecture 架构，提供以下核心功能模块。

## 应用导航

应用底部导航栏包含五个主要入口：

| 入口 | 功能 |
|------|------|
| 首页 | 今日/本月消费概览、快捷操作 |
| 账单 | 消费记录时间线、筛选与搜索 |
| 功能大全 | 热水查询、账单统计等扩展功能 |
| 账号 | 身份和账号管理 |
| 设置 | OCR 配置、数据管理、关于 |

## 首页概览

首页提供一目了然的消费概况：

- **今日消费**：当天累计消费金额
- **本月消费**：当前月份累计消费金额
- **快捷同步**：一键触发账单同步

数据来源于本地 Room 数据库，展示速度不受网络影响。数据在每次同步后更新。

## 账单明细

账单页以时间线形式展示每笔消费记录，包含以下信息：

- **交易时间**：消费发生的时间
- **交易金额**：消费或充值金额
- **商户名称**：消费地点（食堂、超市等）
- **交易类型**：消费/充值/补助等
- **交易号**：唯一标识，用于去重

支持按时间范围筛选和关键词搜索。

点击单条账单可进入 **账单详情** 页面，查看该笔交易的完整信息。

### 账单分类

应用内置消费分类系统，自动对每笔消费进行归类。分类规则由 `cas_lib` 中的 `BillClassifier` 实现，基于三套规则文件：

| 规则文件 | 分类依据 | 示例 |
|----------|----------|------|
| `type.toml` | 交易类型 | 消费、充值、补助等 |
| `position.toml` | 消费地点/商户 | 食堂、超市、图书馆等 |
| `schedule.toml` | 时间段 | 早餐、午餐、晚餐等 |

分类结果用于账单统计页面的数据聚合，帮助用户更清晰地了解消费结构。

### 账单统计

账单统计功能提供多维度消费数据分析，位于 **功能大全** 页面中：

- **按时间统计**：查看日、周、月、年的消费趋势
- **按分类统计**：了解各消费类别的占比和金额
- **按商户统计**：哪些地方消费最多
- **趋势图表**：直观展示消费变化

统计数据来源于本地 Room 数据库，无需网络即可查看。

## 热水查询

热水查询功能实时获取宿舍楼栋的热水供应信息：

- **温度**：当前热水温度
- **水位**：热水储水量百分比
- **楼栋号**：查询的楼栋编号

用户可以关注常用的楼栋，方便快速查询。关注的楼栋列表会持久化存储，但热水数据本身是实时查询，不保存历史记录。

详细用法见 [热水查询](/guide/hot-water)。

## 账号管理

### 身份与账号层级

应用采用 **身份 → 账号** 两级结构：

- **身份**：代表一个人，可自定义名称（如"我自己"、"家长"）
- **账号**：归属在某个身份下，对应一个学号和密码

一个身份可以有多个账号（如同时有本科生号和研究生号），每个账号的账单数据独立存储在各自的 Room 数据库中。

### 安全存储

密码等敏感信息使用 Android `EncryptedSharedPreferences`（AES256_GCM 加密）存储，确保即使在 root 设备上也难以直接读取。

## 设置

设置页面提供以下配置项：

- **OCR 模式**：选择验证码识别方式（手动/远程/本地）
- **远程 OCR 地址**：配置 OCR 服务器 IP 和端口
- **数据管理**：清除本地数据等操作
- **关于**：应用版本信息

## 技术架构

应用的技术栈：

- **UI 层**：Jetpack Compose + Material3
- **依赖注入**：Hilt
- **数据存储**：Room（账单、关注楼栋）+ EncryptedSharedPreferences（密码）
- **网络请求**：OkHttp
- **CAS 认证**：cas_lib 纯 Kotlin 库
- **OCR 推理**：shmtu_ocr（NCNN + OpenCV，C++ JNI）
- **账单分类**：cas_lib 内置 BillClassifier（基于规则文件）
- **账单统计**：本地 Room 数据聚合，多维度图表展示
