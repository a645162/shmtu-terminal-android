# 海事终端

是上海海事大学的一个第三方软件软件

## 账号管理

支持多个身份（人），每个身份支持多个账号（比如本科，硕士，博士拥有不同的学号）

## 账单

这是一个记账功能，能够根据学号调用登录流程，以及接口获取某个账号下的所有账单！
能够将同一个身份的多个账号的账单根据时间顺序进行合并！
